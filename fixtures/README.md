# Fixtures — provenance and reviewed expectations

## scores/wohlfahrt-op45-bk1.pdf

Franz Wohlfahrt, *Sixty Studies for the Violin*, Op. 45, Book 1.

- **Composer**: Franz Wohlfahrt (1833–1884).
- **Copyright**: public domain. The composer died in 1884 and this is a
  19th-century engraved edition (plate number 17549 is printed in the lower
  left of each page).
- **Provided by**: the repository owner, placed in the repo before the build
  began. Not downloaded by this project.
- **Nature**: a genuine 300-DPI-class raster scan. 23 pages, one image per
  page, **no text layer** — `page.get_text()` returns empty on every page. This
  matters: nothing here can be read out of the PDF structure, so recognition is
  doing real work rather than parsing embedded text.

### Why this score

Etude engraving is the cleanest printed violin notation available in the public
domain, which maximises the chance the live upload path works — the stated
priority for this build. Page 3 was chosen as the working page because it
carries **two etudes**, giving genuine difficulty contrast on a single page:

| Region | Etude | Key | Meter | Character |
|---|---|---|---|---|
| systems 0–4 | No. 2, Allegro moderato | C major | 4/4 | steady eighth notes, first position |
| systems 5–10 | No. 3, Moderato | G major | 2/4 | sixteenths and 32nds, wider range |

The key and meter change between them is also a legitimate structural boundary
for segmentation to find, rather than one invented for the demo.

### Honest limitation

Book 1 is beginner repertoire. Expected difficulty ratings land roughly in the
1.5–5 band, so a real page of this score will **not** produce an 8.0+ maroon
measure. No rating is inflated to make the ribbon look better. The legend
renders the full 0–10 scale with all five category labels regardless of what
the loaded score actually spans.

## scores/mozart-k156-mvt1.mxl

Mozart, String Quartet No. 3 in G major, K. 156, first movement. Compressed
MusicXML (`.mxl`), 13 KB, copied unmodified from the corpus bundled with
music21, which distributes it as public-domain material.

Committed as the MusicXML import fixture because it is real violin repertoire
rather than a synthetic test file, and because it exercises parts of the
pipeline the Wohlfahrt scan does not:

| Property | Value | Why it matters here |
|---|---|---|
| Parts | 4 (Violin I, Violin II, Viola, Cello) | The importer takes the first part and says so, rather than silently analysing a cello line |
| Violin I measures | 180, engraving to 2 pages | Exercises the same "page 1 only, and say so" rule the PDF path uses |
| Meter / key | 3/8, G major | Neither matches the scan fixture, so meter handling is not tested against one case |
| Content | ties, 8 chords (double stops), quarters through 16ths | Exercises `double_stops`, tie handling and mixed values in the rubric |
| Format | a real zip container with `META-INF/container.xml` | Exercises the `.mxl` path rather than only plain XML |

**Why this fixture matters for the product claim.** All 145 measures on page 1
come out `confident` and rated, spanning 0.0–7.6. Nothing is "Needs review",
because there is nothing to misread: the notes come from the file and the
measure geometry is read out of Verovio's engraving rather than detected. The
contrast with the scan — where 18 of 61 measures are hatched — is the honest
demonstration that the difficulty analysis is not downstream of OCR quality.
